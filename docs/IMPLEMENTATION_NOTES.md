# 实现说明与研究边界

## 建模流程

项目采用形态发现与监督分类的两阶段流程：以训练期的日内价格路径拟合 K-Shape，再使用历史分钟序列和开盘统计特征预测当天的形态类别。当前实现用于机器学习量化研究，尚未提供交易回测或实盘验证。

## 明确的实现约定

| 项目 | 当前实现 |
| --- | --- |
| 分钟窗口 | 前一交易日最后 230 根与当前日最初 10 根，共 240 根 |
| 输入字段 | open、high、low、close、volume、amount |
| 截面特征 | 显式定义 25 维特征，训练与推理使用相同 schema |
| 午间历史收益 | 上午最后 5 根与下午最初 5 根组成十根窗口，包含午休两端跳变 |
| 价格标准化 | 逐序列使用 `(p - mean) / std` |
| 聚类拟合 | 仅训练期拟合，验证与测试使用冻结中心 |
| 标签分配 | 用完整线性归一化互相关计算 SBD，避免复用训练样本范数 |
| 类别映射 | 中心与上行、下行、震荡原型一对一匹配，另保存相关性供人工检查 |
| 网络 | 双层 64 隐藏维 GRU；截面网络 25→64→32；融合网络 96→32→3 |
| 归一化层 | LayerNorm，支持末批仅一个样本 |
| 优化 | AdamW，默认最多 100 轮、batch 256、验证损失早停 |
| 数据划分 | 由训练与验证截止日期定义三个不重叠的日期集合 |
| 评价 | Accuracy、Balanced Accuracy、Macro-F1、混淆矩阵和训练多数类基准 |

预测标签为全天形态，其中包括已观测的开盘十分钟。因此任务应描述为早期形态分类，不能直接将分类准确率解释为未来收益预测能力。初始化原型也不能保证最终中心具有固定的经济含义，需检查实际训练结果。

## 存档脚本与当前入口

`archive/` 包含早期实验脚本，不属于支持的运行入口。它们使用过不同簇数、特征维数、标准化方式和训练配置，不能将各脚本结果直接拼接为统一实验。当前使用 `intraday-patterns` 命令，并以 `docs/DATA.md` 的数据契约为准。
